## 怎么背｜把记忆量压到可用程度

1. **必背：**各页四段连续骨架；跨题复用高频母句。Task 1 重点是 Overview；Task 2 重点是立场/直接答案与主体逻辑。
2. **选背：**有需要再加入让步拉回、outweigh比较、未来地图、自然循环等模块。
3. **了解：**完整参考稿的题目词汇、更多同义表达；不要求整篇死背。
4. 闭卷写骨架 → 用新题替换 [ ] → 核对信息/论证 → 检查词数与语法。不要仅把占位符替成几个词就视为完成。

**方括号规范：**模板中的 [POINT] 是待填位置；短套用中的 [实际英文内容] 是已填示范。正式考试删除 [ ]。两者都不是可以照搬到任何题目的事实。

目标范围：Task 1 **150–170词**，Task 2 **260–290词**；以题目与内容为先，不为某段长度补废话。官方最低要求分别为150和250词，四段及上述分配是本区训练方法。[IELTS官方写作说明](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing)
