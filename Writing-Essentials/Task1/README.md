| [动态图](dynamic-charts.md) | 多个年份：趋势、起终点、交叉 |

| [高频母句](sentence-bank.md) | 最少必背表达 |

**背诵顺序：**先高频母句，再对应题型的引言和总览/立场，最后练两个主体段。粗体提示优先级，[ ] 标记替换内容。不要把骨架字数当成实际成稿字数。
