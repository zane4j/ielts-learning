## V0.2 创造性复用结果（旧版初筛）

上一版只认可原故事已给出的事实，因此覆盖范围过窄。这一版允许为 Zoe 安排**假设的学习经历**、切换主角，并只增加最小模块。

| 分类 | 题数 | 含义 |
| --- | ---: | --- |
| **S：母版可高度复用** | **4** | 原故事主线，大量句子保留 |
| **M：少量增量模块适配** | **20** | 同一主题链增补几句/切换人物 |
| **N：还需独立事件** | **30** | 不能只靠换人称解决主角或事实类型 |

**S+M 共 24 个候选方向**，但 M 项必须写到足以回应 Cue Card 才能算完成；不意味着目前有 24 篇已经可上考场的答案。

最优先的两篇：[P16 擅长学习语言](CREATIVE_VARIANTS.md#p16--describe-a-person-who-is-good-at-learning-languages)、[P01 做成困难事情的人](CREATIVE_VARIANTS.md#p01--describe-a-person-who-achieved-something-difficult)。两篇主要复用 `struggle → immersive environment → practice → progress → influenced my Philippines plan`。

## 优化方向

1. 保留原 Zoe 的三段式框架与 Example A，不碰定稿。
2. 先输出 A 类的共用主故事，以及每题少数“差异句”，测真实的新增记忆词数。
3. B 类明确哪些 Cue Card 信息缺失，能自然自洽补充练习情景才加；不能满足题意仍暂缓。
4. 下一轮才讨论是否增加一段极短的新经历，以“新增记忆成本 / 新增有效题数”衡量值不值。
5. 如扩大题库，必须先确认仅限中国大陆，和仓库原 54 题分列，不混入海外题。
