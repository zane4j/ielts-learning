## 第一轮结论

| 类别 | 题数 | 含义 |

### 最值得先练的 3 题

- [P09 受欢迎的人](../topics/people/README.md)：Zoe 的旅行视频与粉丝、对我的影响。
- [E16 改变重要观点](../topics/events/README.md)：从担心收入到重新评估职业选择。

**注意：**A 表示故事内容直接可用于作答，并非三个不同题目可以不改动 INTRO / WHAT / WHY 而直接背同一篇稿。

## 优化方向

1. 保留原 Zoe 的三段式框架与 Example A，不碰定稿。
2. 先输出 A 类的共用主故事，以及每题少数“差异句”，测真实的新增记忆词数。
3. B 类明确哪些 Cue Card 信息缺失，有真实素材才补；没有就继续判 C。
4. 下一轮才讨论是否增加一段极短的新经历，以“新增记忆成本 / 新增有效题数”衡量值不值。
5. 如扩大题库，必须先确认仅限中国大陆，和仓库原 54 题分列，不混入海外题。
