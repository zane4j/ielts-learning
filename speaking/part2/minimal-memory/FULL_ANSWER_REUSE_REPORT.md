## 统计口径

- 每篇的英文正文严格为 **5 个自然段**；排除 Topic、Cue Card、关键词清单、中文批注和重复展示的 CORE 栏。
- 以英文句号/问号/感叹号切分句子，完全一致的英文句子（忽略首尾空格和大小写）在**至少两篇不同答案**出现，才算“跨文章可逐字复用”。
- **逐字整句复用率** = 本文中上述重复句子所含词数 / 本文总英文词数。分子不计近义句、相似片段，也不按“这个单词重复了”计入。
- 英文词数用英文字母及英文缩写计数；词数是准备长度指标，不等于考试评分。模板的共同词也可能计入精确重复；这不同于“故事正文独立复用率”。
- 即便某篇复用率较高，也必须回答该题全部 Cue Card。部分背景是创作练习，特别是 L08 的“到访宿务”不能当作用户真实发生的事实。

**V0.5 的高复用优化：** 11 篇人物题统一完整首句；E01 与 E13 共享 INTRO / WHAT 事实段 / 结尾；E02 的英语学习句改为与人物篇完全相同。仍保留每题专属的 Cue Card 行动、结果与 WHY。

> 指标是**文本层面重复率**，不代表口头熟练度、口语评分或题库命中率。

## 记忆策略

1. 优先背下 SHE / TRAVEL / ME 三条 CORE 的完整英文句子，而不是把 25 篇逐篇背下来。
2. 人物类共用相似的 WHO/WHAT/WHY 句式；事件类以相同的 ME 故事作背景，必须另有能答题的动作和结果。
3. **五行提示词**分别对应五个段落，每行的关键词在同一段英文中已经加粗。
4. 如果某题复用率低但能直扣题，比强迫复用率达到 70% 更值得保留。
5. 想在 2 分钟内完成，可先删去例子中不影响 Cue Card 的辅助描述。正式口语的时长需用录音核实。
