## 每篇复盘建议顺序

1. 对照真题问法和四段结构，先找 Task Response 漏答点。
2. 阅读用户**原始作文**（不修改），确认当时的真实水平。
3. 阅读标记稿：~~错误表达~~ → **修订表达**；回忆为什么修改。
4. 阅读逐段修正版、完整修正版与目标范文。
5. 从高频错误清单选 2–3 项，重写一段，隔几天再盲写整篇。
