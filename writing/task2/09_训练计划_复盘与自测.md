> 以 P/C/A/E/F → 80–100 词 Body → 250 词以上整篇作文递进训练。

## 练习安排

1. 2 分钟判断题型与 Scope，写下立场。
2. 5 分钟从 75 个观点选择两条，列出 P → C → A → E/F → Link。
3. 15 分钟完成两个 80–110 词的主体段。
4. 15–20 分钟补全开头与结尾，并检查全文词数。
5. 5 分钟按官方四维评分标准复盘自己容易重复犯的错误。

## 自测清单

- [ ] 两个主体段逻辑链完整且不重复
- [ ] 直接回应题目全部要求
- [ ] 有清晰立场及回扣，比较题真的做了比较
- [ ] 句子自然，词汇搭配正确，避免生硬高级词
- [ ] 全文至少 250 词，留有语法和拼写检查时间

## 原资料组合与边界

### 6.6 如何和第 2 节 Topic / 观点库组合
以后写作文时，不需要重新发明观点。模板和观点库按下面的顺序组合：  
1｜审题 圈出 Topic、Question、Scope、强限定词。  
2｜选母模板 Effects → A；Facts → B；Two-Part → C。  
3｜加模块 需要时插入 Concession / Outweigh / Discuss Both Views / Strong Words。  
4｜选观点 从第 2 节对应 Topic 里挑最贴近 Scope、最容易解释的 2 个观点。  
5｜写逻辑链 每个 Body 先写 P → C → A → E/F → LB，不先写完整英文。  

6｜扩写 把每个槽位扩成 1 句；需要时增加 E2 / E3 或代表性例子。  
7｜检查 LB 是否真正回到题目 Scope；两段是否重复；立场是否前后一致。  
最终记忆卡  
Effects：P → C → A → E → LB  
Facts：P → C → A → F → LB  
Two-Part：一问一个 Body；Cause 看“为什么发生”，Solution 仍用 P → C → A → E → LB。  
真正需要背的是“逻辑槽位 + 高频连接方式”，不是完整范文。  
### 6.7 模板使用边界
这些模板是训练和考场组织工具，不是 IELTS 官方固定格式。实际写作时必须根据题目替换核心名词、因果机制、比较强度和  
Scope；如果模板句与题目逻辑不匹配，应优先保留逻辑而不是强行保留句型。  
来源与边界  
框架直接依据你的 Vince IELTS Writing 讲义及已整理的 Band 6.5 实战笔记：Effects/Facts 的核心逻  
辑、ATES/SFVS/ICESS、CAE/CAF、Social Consensus、Concession & Rebuttal、Scope、四类常见结构。Topic 库中原笔  
记已有的高频方向予以保留；Health、Science、Crime、Family、Transport、Globalisation、Economy、Food、Animal   
Protection 等为按同一 Social Consensus 原则补充的训练分类。  
本文件中的模板属于训练支架，不是 IELTS 官方固定模板。正式写作必须根据题目替换核心名词、逻辑和限定范围。
