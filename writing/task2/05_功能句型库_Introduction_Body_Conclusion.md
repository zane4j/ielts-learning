# 05｜功能句型库

[返回 Task 2 目录](README.md) · [返回 Writing 目录](../README.md) · [返回仓库首页](../../README.md)

> 原资料：Introduction、Body、Concession / Rebuttal、Cause / Solution、Conclusion。

3. 分类模板库：按功能套，不按题目机械背  
模板中的 [X] / [Target] / [Condition] / [Action] / [Effect] 是必须替换的槽位。不要保留与题目无关的套话。你的目标是固  
定“句子功能顺序”，而不是复制固定内容。  
### 3.1 Introduction 模板
A. Facts｜Mostly agree / disagree  
适用 Agree / Disagree，尤其有 most important / best / necessary 等判  
断命题  
结构 Background → Position → 预告主要依据  
模板 [Background sentence]. Although [concession], I largely   
agree/disagree that [statement], because [reason 1] and   
[reason 2].  
使用提醒 必须直接回应命题强度；“X 有价值”不等于“X 是最重要/最好/必  
要”。  
B. Effects｜Positive / Negative development  
适用 Is this a positive or negative development?  
结构 现象 → 总体判断 → 2 个结果方向  
模板 [X] has become increasingly common in recent years. Although   
it may [minor opposite effect], I consider this a largely   
positive/negative development because it can [effect 1] and   
[effect 2].  
C. Advantages outweigh disadvantages  
适用 Do the advantages outweigh the disadvantages?  
结构 承认较弱一边 → 明确较强一边  
模板 Although [X] may cause [main disadvantage], I believe its   
advantages, particularly [advantage 1] and [advantage 2], are   
more significant overall.  
使用提醒 比较题不能只写一边；正文必须真正比较强弱。  

D. Discuss both views + opinion  
适用 Discuss both views and give your own opinion.  
结构 View A → View B → My view  
模板 Some people believe that [View A], while others argue that   
[View B]. In my view, [your position] because [main reason].  
使用提醒 两边必须得到实质讨论。  
E. Two-Part｜Causes + Solutions  
适用 Why...? What can be done...?  
结构 Issue → causes → solutions  
模板 [Issue] has become a noticeable problem in many places. This is  
mainly caused by [cause 1] and [cause 2], and it can be   
addressed through [solution 1] and [solution 2].  
### 3.2 Body：Effects 模板
F. Positive Effect｜PCAE + Link  
适用 优势、正面发展、Agree 的正面理由  
结构 P → C → A → immediate E → further E → Link  
模板 One major benefit of [X] is that it can [Point]. In many cases,  
[Target] face [Condition], which makes it difficult for them to   
[desired result]. By [Action], they are able to [immediate effect].   
As a result, [main effect]. This can further lead to [long-term   
effect]. Therefore, [X] can play an important role in [Scope].  
使用提醒 Condition 很明显时可以缩短，把字数留给 Action + Effect。  
G. Negative Effect｜PCAE + Link  
适用 劣势、负面发展、风险类观点  
结构 P → C → A/situation → E → further E → Link  
模板 One significant problem with [X] is that it may [Point]. This is   
particularly concerning because [Condition]. When   

[situation/action], [Target] may [immediate negative effect]. As   
a result, [main negative effect]. In the long term, this may also   
lead to [further effect]. Therefore, [X] can have a negative   
impact on [Scope].  
H. Comparison｜比较强弱  
适用 advantages outweigh disadvantages / mostly benefits vs   
disadvantages  
结构 承认 A → 指出 B 更直接/更广/更长期 → verdict  
模板 Although [weaker effect] is a genuine concern, its impact is   
relatively limited because [reason]. By contrast, [stronger effect]  
affects [broader target / more important scope] more directly.   
For this reason, I believe the [advantages/disadvantages] are   
more significant overall.  
使用提醒 比较不是简单列 A、B；要写“为什么一边更强”。  
### 3.3 Body：Facts 模板
I. Fact Support｜PCAF + Link  
适用 证明一个 Statement 基本成立  
结构 P/Fact → C → A/behaviour → Fact confirmed → Link  
模板 One important reason why [statement] is valid is that [Fact].   
Many [Target] face [Condition]. In order to deal with this, they   
often [Action/behaviour]. This allows them to [result].   
Consequently, [fact confirmed]. For this reason, [statement] can  
be considered an important factor in [Scope].  
J. Fact Refutation｜攻击强限定词  
适用 the best / the only / the most important / necessary / essential  
结构 承认 X 有价值 → 反例/替代因素 → 证明强命题不成立  
模板 Although [X] can certainly [benefit], this does not mean that it is   
[the best / the only / the most important / necessary] way to   
[goal]. In many cases, [alternative factor] is equally or even   

more important because [Condition]. By [Action], people can   
[Result]. Therefore, [goal] depends on several factors rather   
than [X] alone.  
使用提醒 先攻击限定词，不要只证明 X 有缺点。  
### 3.4 Concession / Rebuttal 模板
K. 让步拉回｜一般型  
适用 Mostly agree/disagree、正负判断、比较题  
结构 Concession → why valid → Rebuttal → priority → Link  
模板 Admittedly, [opposite view] has some merit because [reason].   
However, this does not necessarily mean that [opposite   
conclusion]. When [key condition], [your side] becomes more   
important because [reason]. Therefore, although [opposite   
side] should not be ignored, I still believe that [main position].  
L. 让步拉回｜可控风险型  
适用 某缺点真实存在但可以减弱  
结构 承认风险 → 限制条件 → 减弱风险 → 回主立场  
模板 Admittedly, [X] may [risk]. However, this problem can be   
reduced if [control/condition]. In this case, [positive outcome]  
can still be achieved without causing serious [negative effect].   
Therefore, the overall benefit of [X] remains significant.  
### 3.5 Two-Part：Cause / Solution 模板
M. Cause paragraph  
适用 Why is this happening? / What are the causes?  
结构 Cause 1 → mechanism → result + Cause 2 → mechanism →   
result  
模板 One major cause of [issue] is [cause 1]. Because [mechanism],  
[Target] are more likely to [behaviour/result]. Another   
contributing factor is [cause 2]. When [condition], [result]  
becomes more common. Together, these factors help explain   

why [issue] has increased.  
N. Solution paragraph  
适用 How can this problem be solved? / What should be done?  
结构 Problem barrier → actor → action → immediate result → final   
result  
模板 A practical way to address [issue] is for [actor] to [solution 1].   
This would [mechanism], making it easier for [Target] to   
[desired behaviour]. In addition, [actor 2] could [solution 2],  
which would [effect]. These measures would not remove the   
problem completely, but they could significantly reduce [issue].  
### 3.6 Conclusion 模板
O. Agree / Disagree conclusion  
适用 Facts / Effects 判断题  
结构 总结对方合理处 → 重申立场 → 2 个主要依据  
模板 In conclusion, although [concession] is also important, I believe   
that [main position] because [reason 1] and [reason 2].  
P. Advantages / Disadvantages conclusion  
适用 比较利弊  
结构 承认弱边 → verdict  
模板 In conclusion, while [X] has some disadvantages, I believe its   
benefits in terms of [A] and [B] outweigh these problems.  
Q. Discuss Both Views conclusion  
适用 双方观点  
结构 双方有道理 → 我的判断  
模板 In conclusion, both views have some merit. However, I believe   
that [preferred view] is more convincing because [main reason].  

R. Two-Part conclusion  
适用 原因 + 解决方案  
结构 主要原因 → 主要解决方向  
模板 In conclusion, [issue] is mainly caused by [cause 1] and [cause   
2], and it can be reduced through [solution 1] and [solution 2].
